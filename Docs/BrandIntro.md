# Qpic & impression! 起動ロゴ

最初にtitleシーンへ入ったとき、4.2秒のロゴ演出を表示します。暗い青の情報空間にグリッドとデータの光が点灯し、Qpicの黄とimpression!のシアンをスキャン表示します。最後に団体名を見せて、背後のタイトル画面へフェードします。

0.7秒以降はクリック・Space・Escでスキップできます。タイトルへ戻るたびには再生せず、アプリの再起動またはEditorの再生開始で再び表示します。Time.timeScaleに依存しません。演出中は背後へのクリックとキーボード選択を遮り、終了後にタイトルの選択状態を戻します。BGMの再生・音量は変更しません。

実装はBrandIntroUIとResources/BrandIntroの素材です。RuntimeInitializeOnLoadMethodでtitleシーンを検出するため、シーンへの手動配置や参照の接続は不要です。素材が不足した場合は警告を出し、タイトルへ進みます。

Qpicは提供されたQpicロゴ (1).svgの形を変えず、白いアルファマスクへラスタライズし、実行時に黄で着色しています。元のSVGはDocs/BrandAssets/Qpic.svgに保持します。impression!は提供されたPNGをそのまま格納し、専用シェーダーで白背景を透明化・黒いロゴをシアンへ着色します。両団体のロゴの輪郭や比率は維持しています。新ロゴ案.jpegは配色と2団体の見せ方の参考に使用しました。

シーンの追加、外部動画プレイヤー、追加パッケージは不要です。DurationとRenderAtの時間配分、Logoの色と位置を変更すると調整できます。プレビュー動画は実際のUnity描画を1280×720・30fpsで書き出した無音の確認用です。ゲーム内では既存のタイトルBGMが流れます。

Tools/Validation/BrandIntroChecks.csで、素材の読み込み・スキャン・終了フェード・フォント収録・初回限定・スキップ・入力復帰を検証できます。

## Unityで確認する

1. Assets/Scenes/title.unityを開きます。
2. 上部メニューの「Qpic → ロゴアニメーションを再生」を選びます。
3. 停止中なら再生モードへ入り、再生中ならその場でロゴを最初から流します。何度でも確認できます。

通常の起動時にはSceneLoadedに加えて初期ロード済みシーンも確認します。素材の読み込みに成功した時だけ再生済みと記録します。起動時の自動再生はこれまで通り1回だけです。メニューはEditor専用で、製品版のUIには追加されません。
