# 先攻・後攻のモニター演出

コイントスの表示を、モニター内で「先攻」「後攻」が縦に回転し、減速して中央で止まるスロット形式に置き換えています。止まった後は「あなたは先攻です」「あなたは後攻です」を表示し、中央のハイライトが点滅します。演出を閉じてから初期手札を配り、対戦へ進みます。

既存シーンのCoinTossControllerを入口として使うため、Battleシーンの参照をつなぎ直す必要はありません。CoinUIの旧表示は隠し、仮モニターを実行時に生成します。

## 抽選と進行

- Q/Iの抽選は演出開始時に1回だけ行い、選択キャラの先攻条件でプレイヤーの順番を決めます。キャラクターの条件と確率は従来と同じです。
- 決めた結果に対応する行で回転を止めるため、中央の「先攻／後攻」と実際のターン順が一致します。
- 回転中・結果表示中は入力をロックし、クリックによる再抽選や途中スキップは行いません。
- 演出が中断された場合は結果を確定済みとして扱わず、そのまま対戦へ進みません。
- 重複した再生要求は、先に始まった演出が終わるまで待ちます。

## 調整

BattleシーンのCoinTossControllerで次を調整できます。

| 設定 | 初期値 | 内容 |
|---|---|---|
| Spin Duration | 2.2秒 | 高速回転から減速・停止まで |
| Result Hold | 0.8秒 | 止まった結果を見せる時間 |
| Minimum Rows | 14 | 回転中に通過する行の数の目安 |
| Monitor Artwork | 未指定 | 後から追加するモニターのSprite |

前後に0.15秒ずつフェードし、全体で約3.3秒です。旧Toss Durationは既存データとの互換性のため残していますが、新しい演出では使用しません。

## モニター画像の差し替え

用意した画像をUnityでSpriteとして取り込み、CoinTossControllerのMonitor Artworkへ指定してください。画像がない間は四角形の本体・画面・台座を表示します。画像を指定すると本体がそのSpriteに変わり、仮の台座は表示しなくなります。

画面の位置や大きさを合わせる場合は、CoinTossControllerと同じGameObjectへTurnOrderSlotUIを追加してください。既存コンポーネントを自動で見つけて使います。Monitor Size、Screen Size、Screen Offset、Fade Durationを調整できます。新たなシーンやCanvasの追加は不要です。

日本語テキストはゲーム共通のJikiTourai SDF_Completeを使用します。フレームのサイズは初期値860×500、内部画面700×280、画面位置は中央から上へ30です。
