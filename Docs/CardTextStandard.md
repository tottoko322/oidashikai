# 文章の統一基準

「Q-Gi-Oh!文章データ一覧 (1).docx」を基準とし、全24枚の名称・コウカ文・能力値・
図鑑紹介をCardTextCatalog.jsonへ収録。注記の「変更可能性あり」「ゲーム内と変更あり」
や局会の改名予定の説明は、プレイヤーに表示する文章には含めない。

現在の13枚には、displayName・sortReading・effectDescription・encyclopediaDescriptionで反映。
図鑑はコウカと紹介文を表示し、英字名も読み方で並べる。
UI上の表記はコウゲキ・ボウギョ・コウカ・山札・ごみばこ・ターン・ダメージに統一する。

学祭は射的へ改名。合宿のHP2回復のカードはBBQへ引き継ぐ。
カードID・ファイル名・GUID・デッキ参照を維持し、能力値や効果処理は変更しない。
運動会・Qpic釣り部などの新カードは文言のみ収録し、未実装として区別する。
imp!inter.の読みは資料に明記がないため未指定。

画像に描き込まれた名称・説明は画像の差し替え時に更新する。
山札40枚・コウカ4枠と古い順の消滅／発動、新カードの処理は別のルール実装作業とする。
本変更は新しいカードを対戦デッキへ追加しない。

検証はCardWordingChecks.Runで、全24枚の基準データ、既存13枚の名称・コウカ・紹介・
能力値の一致、図鑑の表示範囲と文字、読み方の並び順を確認する。
