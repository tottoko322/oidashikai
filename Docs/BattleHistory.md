# 対戦ログと墓地

対戦画面のターン表示の上に「ログをみる」、下に「すてふだをみる」を追加。
BattleStateMachineが既存Canvasに自動生成するため、シーンへの手動配置は不要。

ログは新しい記録を上に表示し、ホイールやドラッグでスクロールできる。
先攻、各ターン、コウゲキ・こうか・ボウギョで使用したカード、効果で捨てたカード、
ドロー枚数、ダメージ・回復後のHP、予約効果、最大HP変更、スキップ、勝敗を記録する。
相手の未公開の手札・ドローしたカード名・山札の並びは記録しない。

墓地には使用したカードと効果で捨てたカードが入る。
「じぶん」「あいて」で切り替え、カードの画像・用途・ターンを確認できる。
カードのクリックで拡大し、背景クリックまたはEscで一覧へ戻る。
同じCardDataの複数枚も、実際に使用・破棄した枚数で数える。
キャンセルしたドラッグ、使用条件を満たさない操作は墓地に追加しない。

閲覧は対戦の時間や入力ロックを変更しない。閲覧中の背後へのカード使用、
ボウギョ選択、スキップ操作は拒否する。CPUの処理は進み、ボウギョが必要な場合は
閲覧を閉じてから選択できる。勝敗表示で時間が停止した後も閲覧できる。
記録はその対戦限りで、新しい対戦には引き継がない。

BattleHistoryは公開情報の記録データ、BattleHistoryUIは閲覧画面を担当。
現在のNPC戦に組み込んでおり、オンライン同期自体は含まない。
墓地から戻す処理や、新しい墓地関連ルールは追加しない。
手札上限時のドロー等は既存ルールを使用する。

検証: Tools/Validation/BattleHistoryChecks.csは、双方の使用・ボウギョ・破棄、
同名カード、ドローの公開範囲、不成立操作、HP変化、勝敗の重複防止、
閲覧のスクロール・切り替え・拡大・再表示・終了処理を確認する。
