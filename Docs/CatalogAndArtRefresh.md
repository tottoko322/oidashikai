# 図鑑と画像の更新

UIの表示用語を「コウゲキ・ボウギョ・キャラクター・クリック・スキップ・カード」に統一。
既存のJikiTouraiを見出しに使い、図鑑の紹介文には提供されたWDXL Lubrifont JP Nを使う。
JikiTouraiにない文字にも同フォントをフォールバックとして使用する。
フォント本体とOFLライセンスは `Assets/Resources/Fonts` に保存。

## 図鑑

`Assets/Data/Card/*.asset` の `Encyclopedia Description` が紹介文。
QGOカード説明.docxにある12件をそのまま収録。
PJは追加指定に基づく「Planning Jam。作るゲームの構想を立てる。」を収録。
カードのクリック時にCardDataから紹介文を読み、説明ボタンで表示する。
紹介文は対戦ルールとは独立したデータで、カード効果は変更しない。

## あそびかた

RuleシーンのSlideControllerは現在、新しいHow_To_Play1・How_To_Play2だけを参照。
新しい画像の矢印と×に透明な操作領域を合わせ、縦横比を維持して表示する。
画像内に描かれた1/6・2/6は提供画像のまま。実際に移動できるページは2枚だけ。
3枚目以降が届いたら、Image 3・Image 4とAdditional Pagesに順番に設定できる。

## カード画像と相手アバター

部室と講座は提供PNGへ差し替え。部室のCardDataは仮画像への参照も解除。
画像は単一の全体Spriteとして扱い、旧画像のスライスを残さない。
BattleシーンのEnemy Portrait Frameは既存の上側フレームを参照。
枠の内側に合わせた円形ステンシルで、相手の画像とダメージ時の移動を切り抜く。
元のImage・クリック処理・被弾色の点滅は引き続き使用する。

## 検証

Unity 6000.4.11f1の独立した検証プロジェクトで、CatalogRefreshChecksを実行。
全13件の紹介文と漢字の生成、新画像参照、2枚のナビゲーション、図鑑の選択更新、
両キャラクターの円形マスクと被弾後の位置復帰を確認。実際のレンダリングも確認。
既存のCPU・フォント検証も実行する。
