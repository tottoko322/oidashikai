# ゲームの共通フォント

ゲーム画面のTextMesh Proテキストを、Assets/TextMesh Pro/Fonts/JikiTourai SDF_Complete.assetへ統一しています。

タイトル、キャラクター選択、対戦、図鑑、ルールの各シーンと図鑑カードのPrefabは、Font Assetと共有マテリアルの両方に同じCompleteアセットを設定しています。文字サイズ、色、配置は維持しています。漢字に対応しないフォントのため、難易度・先攻後攻・CPUの行動・効果詳細などの文言はひらがな・カタカナ表記にしています。倍率の記号も収録済みの半角xを使います。他フォントへのフォールバックは追加していません。

Assets/Script/Effect/Resources/TMP Settings.assetのDefault Font Assetも同じアセットです。新しく作成するTextMesh Proテキストも、このフォントが初期値になります。難易度、CPUのリソース・使用カード、先攻後攻モニターの動的生成テキストはGameFonts.Applyで共通フォントとそのマテリアルを設定します。

以前の「シーン内で見つかったフォント」や「名前にCompleteが含まれるフォント」の検索は使用しません。フォント本体の移動やコピー、文字の画像化は行っていません。

カードの絵など、画像素材に元から描かれている文字はTextMesh Proのフォント設定では変わりません。

Completeの静的アトラスには半角スペース(U+0020)もないため、GameFontsは起動時に空白のグリフをメモリ上で1回だけ補います。別フォントや別テクスチャは使わず、元の67MBのアセットも書き換えません。空白以降の文字がTMPの終端文字に置き換わるのを防ぎます。
